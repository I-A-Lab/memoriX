# Part 40.6 — Retrieval diagnostic

This campaign corrects positive versus negative evaluation and compares:

- lexical control;
- raw Titan hot-site retrieval;
- real memoriX ingestion with benchmark-only metadata-aware reranking.

A strong hybrid improvement proves that records were stored but raw candidate
generation or routing failed. It must not be reported as raw Titan quality.
All outputs and runtimes are preserved outside the repository.
